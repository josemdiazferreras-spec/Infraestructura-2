# Nota de seguridad

El respaldo original del FortiGate contiene credenciales/certificados cifrados y **no debe publicarse** en un repositorio público. Este repositorio usa `fortigate-backup-SANITIZED.conf`, donde se sustituyeron contraseñas, PSK y claves privadas por marcadores `<REDACTED_...>`.

La PSK real usada durante el laboratorio no se publica. Si el docente exige el archivo exacto, entréguelo por un canal privado o use un repositorio privado.
